### **OSC2 Studio: Online OpenSCENARIO 2.0 Scenario Editor**

**Making the power of OpenSCENARIO 2.0 truly accessible.**

#### **Overview**
**OSC2 Studio** is a lightweight, ready-to-use online editor specifically designed for **OpenSCENARIO 2.0** scenario development in the autonomous driving simulation domain. It requires no environment setup – simply open your browser to start writing, editing, and saving OSC2 format scenario files efficiently, boosting your development productivity.

#### **Core Features**

*   **Streamlined File Operations**
    *   **Open**: Directly load and edit local OSC2 scenario files.
    *   **Save**: Export your edited scenario code as a standard OSC2 file to your local machine.
*   **User-Friendly Interaction**
    *   **Theme Switching**: Switch between light and dark themes to suit different lighting conditions.
    *   **Multi-Language Interface**: Supports Chinese, English, German, and Japanese.
    *   **Toolbar Shortcuts**: Essential editing functions like Undo, Redo, Select All, and Find.
*   **Intelligent Code Editing**
    *   **Syntax Highlighting**: Clearly distinguishes code structure for better readability.
    *   **Real-Time Code Checking**: Instantly marks syntactic and grammatical errors, aiding quick debugging.
    *   **Auto-Completion**: Provides context-aware code completion suggestions to reduce input errors.
*   **Excellent Performance**
    *   Core functionalities are implemented in **C++/WebAssembly**, ensuring a smooth editing experience even when handling large OSC2 files.
